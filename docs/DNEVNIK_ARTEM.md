## 4. Индивидуальное задание и отметка о выполнении

### Индивидуальное задание
*(выдаётся руководителем практики от университета)*

**Студент:** `[Фамилия Имя Отчество (Артём)]` (Backend-разработка: учёт оборудования, справочники и импорт Excel)

Спроектировать и реализовать серверную подсистему предметного учёта и справочников информационной системы «Учёт материальных ценностей» кафедры ПиСП на базе Node.js, Express, TypeScript, Drizzle ORM и PostgreSQL.

В рамках задания необходимо выполнить следующие работы:
1. Разработать реляционную схему базы данных для сущностей аудиторий (`room`), иерархии типов имущества (`equipment_type` с самоссылкой), настраиваемых дополнительных полей (`additional_field`) и основного реестра оборудования (`equipment`).
2. Реализовать REST API управления кабинетами (включая безопасное удаление с проверкой привязанного имущества и возвратом `409 Conflict`) и деревом типов оборудования (включая защиту от циклических ссылок при смене родителя).
3. Создать универсальный серверный движок валидации динамических характеристик оборудования с рекурсивным наследованием активных полей по цепочке родительских типов и проверкой стандартных бухгалтерских полей кафедры, включая обязательность категории учёта и содержания драгметаллов.
4. Реализовать API многокритериальной фильтрации и пагинации каталога оборудования, массового удаления, генерации эталонного Excel-шаблона и пакетного импорта бухгалтерских ведомостей с двухэтапной обработкой дубликатов при сохранении исходных инвентарных номеров без модификаций. Провести тестирование API и валидации.

### Отметка о выполнении индивидуального задания
Индивидуальное задание выполнено полностью. Реализованы таблицы и связи справочно-учётной базы данных, движок иерархической валидации дополнительных полей, многокритериальная серверная выборка и интеллектуальный импорт из Excel с сохранением бухгалтерской точности инвентарных номеров. Все маршруты успешно протестированы.

## 5. Отчёт о выполнении программы практики

*(УТВЕРЖДАЮ: Кафедра ПиСП)*

С 2 по 14 октября 2026 года я проходил производственную (технологическую) практику на кафедре прикладного и системного программирования ВГУ имени П.М. Машерова. Моей задачей в командной разработке ИС «Учёт материальных ценностей» стало создание серверного ядра учёта имущества, справочников и работы с таблицами Excel.

В процессе проектирования базы данных на PostgreSQL с использованием Drizzle ORM была выбрана гибридная модель хранения: базовые реквизиты (инвентарный номер, наименование, стоимость, дата поступления, ссылки на кабинет и тип) вынесены в строгие реляционные столбцы, а изменяемые характеристики различных видов техники сохраняются в JSON-поле под контролем серверного валидатора.

Мной разработан модуль рекурсивного наследования полей типов оборудования и проверки 19 стандартных полей кафедры, настроено защитное удаление аудиторий и типов (с проверкой зависимых записей и отсутствия циклов в иерархии), а также реализован эндпоинт расширенного поиска и фильтрации реестра. Отдельное внимание уделено подсистеме пакетного импорта бухгалтерских Excel-файлов: реализованы нормализация форматов, автосоздание справочников и интерактивная обработка совпадений с сохранением неизменных инвентарных номеров для комплектов имущества.

По итогам практики серверная подсистема учёта прошла полную проверку типов, интеграционное тестирование с клиентской частью и готова к эксплуатации.
